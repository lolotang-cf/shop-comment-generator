API 接入配置（多通道自动故障转移）

通道 1（主用）—— 必填，至少一个带 Key 的通道
通道 2（备用）—— 主用失败自动切换，强烈建议填硅基流动免费 Key

    

      配置仅保存在本机浏览器 localStorage，不上传任何服务器。
